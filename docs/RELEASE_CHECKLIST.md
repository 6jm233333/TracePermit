# v1.0.0 Release Checklist

This repository is organized for the fixed `v1.0.0` public release of TracePermit. The GitHub tag/release should stay aligned with the repository URL, and the Zenodo DOI should be filled in once archival is complete.

## GitHub

1. Keep the public repository URL fixed to `https://github.com/6jm233333/TracePermit`.
2. Keep the release tag and release page fixed at `v1.0.0`.
3. Keep `CITATION.cff`, `metadata.json`, and `README.md` aligned with the published tag.
4. Keep `CHECKSUMS.sha256` in sync with the release tree.

## Zenodo

1. Publish or link the archival record for the `v1.0.0` tag.
2. Update `.zenodo.json`, `CITATION.cff`, and `metadata.json` with the DOI after publication.
