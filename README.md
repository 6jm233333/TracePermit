# TracePermit v1.0.0

TracePermit is the companion research repository for **“TracePermit: Group-Isolated Evaluation of Contextual Release Decisions for Aviation-Engineering Language Assistance.”** It provides a de-identified contextual-release benchmark, frozen controller outcomes, the public study policy, and lightweight verification/re-aggregation code.

## Data at a glance

The release contains **2,072 de-identified traces** across seven frozen partitions: `core_train` (288), `core_validation` (96), `test` (96), `challenge` (120), `development_stress_train` (864), `development_stress_validation` (288), and `heldout_known_stress` (320).

The 600 core traces were independently labelled by three qualified aircraft-engine experts under the written study policy. Pre-adjudication nominal inter-rater reliability was Krippendorff's α = 0.79; final core labels are 167 `allow`, 233 `review`, and 200 `block`. Rater-level records and written rationales are not distributed.

The 1,472 stress reference actions were obtained by reapplying the study policy after declared contextual transformations; they were not independently reannotated trace by trace. Held-out known stress contains four families with 80 traces each: access-scope flip, cyber-status flip, output-sensitivity flip, and prompt-injection insertion.

## Quick start

Python 3.10+ is sufficient for the public verification and re-aggregation scripts, which use only the Python standard library.

```bash
python scripts/verify_release.py
python scripts/summarize_results.py
python -m unittest discover -s tests -v
```

The optional training, inference, evaluation, prompt, hyperparameter, and model-access instructions are in `docs/TRAINING_INFERENCE_EVALUATION.md` and `docs/MODEL_ACCESS.md`. The default training command is a no-download dry run; model weights and private checkpoints are not redistributed.

To reproduce the paired stored-group bootstrap summaries used for controller comparisons:

```bash
python scripts/summarize_results.py --bootstrap 10000 --seed 2026
```

## Evaluation records

`outcomes/rule_conservative_outcomes.jsonl` contains deterministic outcomes for Test, Challenge, and held-out known stress. `outcomes/learned_heldout_outcomes.jsonl` contains all 18 model-seed-condition cells for Qwen3-14B, Phi-4, and OLMo2-13B under LoRA and Stress-LoRA on the same 320 held-out known-stress traces.

The public traces are sanitized research artifacts. They omit raw upstream values, raw timestamps, native HAI `Attack` labels, original source identifiers, source filenames, and trace-to-source mappings. The public serialization therefore supports dataset inspection, group/split verification, and re-aggregation of the released outcomes; it is not claimed to be byte-identical to the private execution inputs used for model inference.

## Reproducibility boundary

This public release is designed to support independent inspection of the benchmark, verification of frozen partitions and group isolation, validation of released artifacts, and re-aggregation of the reported controller-level outcomes. It does **not** claim bitwise reproduction of the private training or inference runtime, and it does not redistribute private checkpoints, model caches, or raw upstream inputs.

## Scope

TracePermit evaluates a study-defined contextual release decision (`allow`, `review`, or `block`). It does not establish operational aviation certification, specialist-review performance, authenticated access control, forensic cyber assessment, or raw-source-document independence. See `docs/DATA_CARD.md` for the full data and validation boundary.
